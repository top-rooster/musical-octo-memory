# FORMAT DRAFT FOR REVIEW
#
# Blank lines separate card masters.
# First line is the card title, second line is its picture path.
# Remaining plain lines are attributes or behavior statements.
# Marker: name only. Value: name followed by integer.
#
# Unless explicitly overridden, all Values are capped from 0 to 100.
#
# Every Action and Process must state an explicit duration.
# Instant Actions use 0m.
# If a Process duration is still undecided, the card is intentionally left
# incomplete here rather than inventing a number.
#
# Compound requirements use +. Example: Fabric+Sterilized means the accepted
# source card must carry both Markers.
# Hyphens in parser-facing attribute names display as spaces in the UI.
# Example: Contains-Water is shown as "Contains Water".
#
# The data below reflects current design decisions where concrete.
# Comments call out values/names/times that are still undecided.
# The syntax itself is not yet a locked design decision.
