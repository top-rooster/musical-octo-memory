# FORMAT DRAFT FOR REVIEW
#
# Blank lines separate card masters.
# First line is the card title, second line is its picture path.
# Optional description: a line beginning with > immediately after picture path.
# Remaining plain lines are visible attributes or behavior statements.
# Marker: name only. Value: name followed by integer.
#
# Milestone 2 adds a small amount of non-attribute behavior metadata:
#   size Small|Medium|Large
#   equip <slot>
#   storage Small|Medium|Large <count> [main]
#   while-equipped <effect>
# These lines describe card behavior and are not additional hidden card attributes.
#
# Unless explicitly overridden, Values are capped from 0 to 100.
# Every Action and Process must state an explicit duration.
# Instant Actions use 0m.
#
# The syntax remains intentionally small and may change when real content needs it.
